# Demo Video Script - AsiaBD Commerce AI (60-90 seconds)

A tight product walkthrough following the core workflow: **select product →
choose Shopify → generate title + description → create ad copy → save/export.**

> **Recorded version:** `public/videos/asiabd-commerce-ai-demo.mp4` is embedded in
the landing page walkthrough section. Keep this script for re-recording with
your own branding whenever the product changes.

Target length: ~80 seconds. Record at 1080p, 60fps, browser zoom ~110%.

---

## Shot list & voiceover

### 0:00-0:08 - Hook (landing hero)
**On screen:** Landing page hero. Cursor moves toward “Start generating free”.
**Voiceover:** “Writing product listings for five marketplaces eats your whole week. AsiaBD Commerce AI writes them for you - in seconds.”

### 0:08-0:20 - Select a product
**On screen:** Dashboard → Quick generate (or Tools → Product Title Generator).
Click the **Skincare** sample chip → form fills with “GlowDrop Vitamin C Serum”.
**Voiceover:** “Pick a product - or load a sample. Every marketplace has its own rules, so first… choose where you’re selling.”

### 0:20-0:35 - Generate title + description
**On screen:** Marketplace dropdown → **Shopify** → Generate. Result cards appear:
3 title options with character counts, then **Save to library** is visible below.
Then open **SEO Product Description**, generate, scroll through SEO title, meta
description, and bullets.
**Voiceover:** “Shopify gets SEO-tuned titles and meta descriptions, within
Google’s character limits. Three options, ready to publish - and every field
stays editable.”

### 0:35-0:50 - Ad copy
**On screen:** Open **Ad Copy Generator** → same product → Generate. Show the
three angles: hook, primary text, CTA.
**Voiceover:** “Turn the same product into ad angles - a problem-solution hook,
a feature spotlight, and a value angle. Copy, paste, launch.”

### 0:50-1:05 - Save & export
**On screen:** Click **Save to library** → toast confirmation. Open **Library**,
search “GlowDrop”, open the saved item, tweak a line, hit **Download** (.txt).
Back on dashboard: show the credits counter decreased by exactly the run cost.
**Voiceover:** “Everything saves to your content library - searchable, editable,
and exportable. Credits only get used when generation succeeds.”

### 1:05-1:20 - Close (CTA)
**On screen:** Cut to pricing or the CTA band. Cursor hovers “Start generating free”.
**Voiceover:** “Nine tools, every major marketplace, one brand voice. Start free
with AsiaBD Commerce AI - fifty credits, no credit card. asiabd.shop.”

## Production notes

- **Demo mode recording:** if recording without an API key, the app shows
  “Demo - sample output” chips. That is fine for a product tour; optionally
  enable `ANTHROPIC_API_KEY` for live generation shots.
- **Cuts:** keep one continuous cursor path where possible; hide notifications.
- **Music:** light, upbeat, low volume (−22 LUFS under voice).
- **End card:** logo + `asiabd.shop` + “50 free credits - start free”.
