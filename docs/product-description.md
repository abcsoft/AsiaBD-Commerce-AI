## Long description

AsiaBD Commerce AI is a focused, vertical SaaS product for one audience:
e-commerce sellers. Instead of a generic “AI tools” dashboard, every feature
maps to the real work of getting products found and sold across marketplaces.

Sellers describe a product - name, category, features, target customer, and
keywords - then choose a marketplace and tone. The suite generates
publish-ready content: three optimized product titles, complete SEO
descriptions with meta fields, a listing audit with concrete fixes, ad copy
angles with hooks and CTAs, platform-ready social captions, professional
customer support replies, reusable brand voice profiles, and long-tail keyword
plans. A bulk generator handles catalogs up to ten products per run, and a
saved content library keeps everything searchable, editable, and exportable
(TXT, JSON, CSV).

Marketplace awareness is built in: titles respect each platform’s length and
keyword conventions (Amazon’s front-loaded attributes, Etsy’s long-tail buyer
phrases, TikTok Shop’s short punchy titles, Shopify’s SEO windows), and a
central rules module makes updates easy as guidelines evolve.

Generation is powered by Anthropic’s Claude, called strictly server-side so
API keys never reach the browser. Every run is metered by a credit system with
a full ledger - and credits are only charged when a generation succeeds.
A demo mode with realistic sample output lets anyone explore the entire
product before configuring live generation.
